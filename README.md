# מסע הכלים

משחק קצר בעברית (כחמש דקות) שעוזר לילדים עם הפרעת קשב לתרגל ולהפנים ארבע אסטרטגיות ניהוליות ברוח שיטת Cog-Fun: **עצור**, **תכנון**, **גיוס מאמץ** ו**בדיקה**.

המבנה והכלים קבועים. התוכן (תחום העניין) מתחלף: כדורגל, חלל, אפייה, או כל עולם אחר שמוסיפים לילד מסוים או לתקופה מסוימת.

> המשחק תומך בתרגול ואינו מחליף טיפול. את המטרות, המצבים מהיום-יום והניסוחים כדאי לתאם עם המרפא/ה בעיסוק.

## איך משחקים

1. בוחרים עולם תוכן. כל עולם הוא משימה אחת ("מתכוננים למשחק הגדול").
2. עוברים ארבע תחנות, לפי הסדר שבו מבצעים משימה אמיתית:

| תחנה | הכלי | מה עושים | משפט המפתח |
|---|---|---|---|
| 1 | עצור | לוחצים על שלט עצור ונושמים. אחר כך פריטים מופיעים אחד-אחד: נוגעים רק במה ששייך למשימה, ועוצרים מול מה שלא שייך | עוצרים. נושמים. מסתכלים. |
| 2 | תכנון | מסדרים את צעדי המשימה לפי הסדר | מה עושים קודם? ומה אחר כך? |
| 3 | גיוס מאמץ | שלושה סיבובי חיפוש שהולכים ומתארכים. לפני האחרון בוחרים משפט שאומרים לעצמנו | זה קשה, ואפשר להמשיך. |
| 4 | בדיקה | משווים את מה שנאסף לרשימה: מה יש, מה חסר, ומה לא שייך | עוברים על הכול. עשינו מה שתכננו? |

3. **כלי אחד לוקחים הביתה**: הילד/ה בוחר/ת כלי אחד ומצב אמיתי מהיום-יום שבו ישתמש/תשתמש בו (שיעורי בית, התארגנות בבוקר...).
4. בפתיחת המשחק הבא המשחק שואל איך הלך, והתשובה נרשמת ביומן.

עקרונות העיצוב: דבר אחד בכל מסך, מעט טקסט, כפתורים גדולים, משוב מיידי וחיובי, ואין עונש על טעות. הניסוח בלשון רבים ("עוצרים", "בודקים"), כך שאין צורך לבחור בן או בת.

## התאמת התוכן לילד/ה

כל ההתאמות נעשות מתוך המשחק, בכפתור **להורים**:

- **הגדרות**: שם, רמה (רגוע / רגיל / מאתגר), ורשימת המצבים מהיום-יום שמתוכם בוחרים כלי לקחת הביתה.
- **עולם חדש**: טופס קצר. ממלאים משימה, פריטים ששייכים, פריטים שלא שייכים וצעדים לפי הסדר. את ארבע התחנות המשחק בונה לבד.
- **שכפול ועריכה**: מתחילים מעולם מובנה ומשנים אותו.
- **ייבוא וייצוא JSON**: לשיתוף עולם בין מכשירים, הורים ומטפלים.
- **בקשה מוכנה ל-AI**: מעתיקים את הבקשה, ממלאים תחום עניין, ומדביקים את התשובה ב"ייבוא עולם".

ההגדרות, העולמות שנוצרו והיומן נשמרים בדפדפן של אותו מכשיר בלבד.

### מבנה של עולם תוכן

```json
{
  "name": "כדורגל",
  "emoji": "⚽",
  "color": "#1F8A4C",
  "guide": { "name": "שועלי", "emoji": "🦊" },
  "mission": "מתכוננים למשחק הגדול",
  "story": "היום יש משחק חשוב, והקבוצה מחכה.",
  "container": { "name": "תיק הספורט", "emoji": "🎒" },
  "needed": ["⚽ כדור", "👟 נעלי כדורגל", "..."],
  "notNeeded": ["📱 טלפון", "🎮 שלט משחק", "..."],
  "steps": ["לובשים את המדים", "נועלים נעלי כדורגל", "..."],
  "search": { "target": "⚽", "others": ["🏀", "🏐", "🎾"] }
}
```

| שדה | משמש בתחנה | דרישה |
|---|---|---|
| `needed` | עצור, בדיקה | לפחות 6 פריטים, עדיף 8 |
| `notNeeded` | עצור, בדיקה | לפחות 4 פריטים, עדיף 7 |
| `steps` | תכנון | 3 עד 6 צעדים, בסדר הגיוני אחד |
| `search` | גיוס מאמץ | אימוג'י אחד לחיפוש ולפחות 3 מסיחים דומים |
| `container.name` | עצור, בדיקה | בצורה מיודעת ("תיק הספורט", "החללית") |

כדי להוסיף עולם מובנה לכולם: יוצרים קובץ בתיקיית `themes/` לפי הדוגמאות הקיימות, ומוסיפים שורת `<script>` ב-`index.html`.

## הרצה

אין התקנה ואין שרת. פותחים את `index.html` בדפדפן, או שולחים את הקובץ היחיד `dist/masa-hakelim.html` לטלפון או לטאבלט.

אחרי שינוי בקוד או בעולמות בונים מחדש את הקובץ היחיד:

```
node tools/build.js
```

## מבנה הפרויקט

```
index.html          העמוד
css/style.css       עיצוב (בהיר וכהה)
js/app.js           מהלך המשחק, ארבע התחנות, אזור ההורים
themes/*.js         עולמות התוכן המובנים
tools/build.js      אריזה לקובץ יחיד
dist/               הקובץ היחיד, מוכן לשיתוף
```

## רקע

Cog-Fun (Cognitive-Functional) היא התערבות בריפוי בעיסוק שפותחה באוניברסיטה העברית. היא מלמדת אסטרטגיות ניהוליות (עצירה, גיוס מאמץ והתמדה, בקרה ותכנון) דרך משחק, בסביבה חיובית ובשיתוף ההורים, ומעבירה אותן למטרות תפקודיות מהיום-יום. המשחק הזה אינו חלק רשמי מהשיטה. שמות הכלים ומשפטי המפתח מוגדרים בראש `js/app.js`, ואפשר להתאים אותם לשפה שבה משתמשים בטיפול.
